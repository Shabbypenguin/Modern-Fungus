# Settings Reference

Every option on the home screen and in online rooms, with the numbers behind it. The home screen saves your choices in this browser.

## Home screen

### Rules
| Option | Meaning |
|---|---|
| Classic | The 1994 game: 2–4 players, original start spots, corner teeth, bites every 80 cells. See [[Rules]]. |
| Modern | 2–16 players on a fair ring, fair teeth, adjustable speeds. See [[Modern Mode]]. |

### Board
| Board | Size | Modern players that fit |
|---|---|---|
| Classic | 20×20 | 2–8 |
| Large | 35×35 | 2–15 |
| XL | 50×50 | 2–16 |
| Mega | 75×75 | 2–16 |
| Massive | 100×100 | 2–16 |

Boards too small for the current number of Modern players are greyed out. Adding players moves you up to the smallest board that fits.

### Game speed (Modern)
Slowest, Slow, Normal, Fast, Fastest. Each sets **New teeth** and **Bite growth** to the matching step. Presets never change the board. See [Modern Mode: game speed presets](Modern-Mode#game-speed-presets).

### Custom settings (Modern)
Opens only when you click it.
| Option | Steps | Effect |
|---|---|---|
| New teeth | Very slow → Very fast | Free bite for everyone every 16–21 / 12–17 / 8–13 / 5–8 / 3–5 rounds |
| Bite growth | Very slow → Very fast | Base cells per bite level: 90 / 70 / 55 / 40 / 28, plus the game's shared roll |

The note under Bite growth shows the full range for the chosen board, for example "Big bites at 57–66 cells".

### Players
- **Classic:** four fixed seats (red, green, blue, yellow), each **Human**, **CPU** or **None**. At least two must be filled.
- **Modern:** a list of 2–16 seats, each **Human** or **CPU**. **Add player** and **×** change the count.
- **Names:** up to 16 characters, and each must be different. Names you've used before are suggested.

### Options
| Option | Values | Notes |
|---|---|---|
| Turn time limit | off, or 3–60 seconds | Local games. Running out passes your turn. |
| Sound | on / off | |
| Interface size | Small 85%, Normal, Large 120%, Larger 140% | Scales the interface on top of automatic sizing. Board zoom is separate. |

## Online rooms
Hosting a room uses your home-screen **rules, board and speeds**. See [[Online Play]].

| Option | Values | Notes |
|---|---|---|
| Turn time | 15, 20, 30, 45, 60, 90, 120 seconds | Default 30. Online games always have a limit. |
| List publicly | on / off | Public rooms show in **Open games** and can be found by Quick play. Private rooms are join-by-code only. |
| Seats (host, in the lobby) | Player / CPU / Closed | Every seat starts as **Player**, open for people to join. Unfilled Player seats become CPUs when the game starts. **Closed** is Classic only. |

## Fixed values
| What | Value |
|---|---|
| Starting bites | 0 |
| Bites per tooth collected | 1 |
| Bite levels | 3: Bites (1 cell), Big (2), Monster (3) |
| Classic bite levels | 80 and 160 cells |
| Stalemate | No moves by anyone for 2 turns per player: the largest fungus wins |
| Online reconnect grace | 60 seconds, then a CPU stands in |
